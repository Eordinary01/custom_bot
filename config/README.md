# Configuration Directory

This directory contains configuration files for the JARVIS assistant.

## Purpose
- System configuration (model settings, performance parameters)
- Personality configuration (formality, verbosity, humor)
- Feature toggles
- Logging configuration

## Files
- `config.json` - Main system configuration
- `personality.json` - Personality profile settings
- `actions.json` - Action mapping configuration
- `schema.json` - Configuration validation schema

## Configuration Format
All configuration files use JSON format with validation against JSON Schema.
